# LoanProduct -- v2.0

**Schema Pack Version:** 2.0.0
**Status:** Initial release

## Notes

Initial release of the LoanProduct schema (`resourceAttributes`) for the Personal Loan
"Personal Loan" use case, converted to Beckn v2.0.0 LTS. Carries rate/tenure/amount
bands, interest-rate type, journey type, and the out-of-band application form link
for a loan-product catalog resource. See `../../ondc_fis_v2_payloads.md` (source
design doc) Section 3 for the full field derivation and Section 4 for `on_discover`
usage examples.
